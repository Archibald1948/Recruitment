# 🚀 개발 프로젝트 팀원을 모집합니다!

함께 아이디어를 구체화하고, 기획 → 개발 → 배포 → 운영까지 직접 경험하며 하나의 서비스를 완성해 나갈 팀원을 모집합니다.

단순히 포트폴리오 한 줄을 채우기 위한 프로젝트보다는, 취업과 실무에 도움이 되는 경험과 역량을 쌓는 것을 중요하게 생각합니다.

서비스를 개발하고 배포하는 것에서 끝나지 않고, 실제 사용자를 모집하고 사용자 피드백을 바탕으로 서비스를 개선하며 직접 운영해 보는 과정까지 경험하는 것을 목표로 하고 있습니다.

각자 맡은 역할만 수행하고 끝나는 방식보다는 기획, 디자인, 프론트엔드, 백엔드 등 각 파트가 서로 적극적으로 의견을 주고받으며 함께 하나의 서비스를 만들어가는 팀을 지향합니다.

또한 지나치게 타이트한 개발 일정보다는 각자의 본업과 개인 일정을 존중하면서 꾸준히 참여할 수 있는 방식으로 프로젝트를 운영하고자 합니다. 다른 파트의 진행에 지장이 없는 범위 내에서 각자의 상황에 맞게 일정을 조율하며 유연하게 개발하는 것을 기본 원칙으로 합니다.

빠르게 만들어 끝내는 프로젝트보다, 끝까지 완성하고 실제 사용자에게 제공하며 운영해 본 경험이 남는 프로젝트를 함께 만들어가고 싶습니다.

# 🙋‍♂️ 팀장 소개

저는 10번 이상의 프로젝트 경험을 비롯해, 3곳의 대학생 개발 연합동아리 활동과 7회 이상의 대회·공모전 참여 경험이 있습니다.

또한 백엔드, 프론트엔드, 모바일 개발까지 폭넓게 경험하며 **풀스택 형태로 프로젝트에 참여해 왔습니다.**

### **주요 기술 경험**

- **Back-End**
    - Spring Boot
    - FastAPI
    - Node.js
    - PostgreSQL
    - MySQL
    - REST API 설계 및 서버 개발
- **Front-End**
    - JavaScript
    - TypeScript
    - React
- **Mobile**(iOS)
    - XCode
    - SwiftUI
    - UIKit

이러한 경험을 바탕으로 이번 프로젝트에서는 특정 파트에만 국한되지 않고, **전체적인 서비스 구조와 각 파트 간의 연결을 이해하며 개발 및 협업 과정에 직접 참여**할 예정입니다.

프로젝트에서는 전체 일정 및 협업 관리와 함께 전반적인 개발 과정에도 참여하며, 필요할 경우 각 파트 간 기술적인 커뮤니케이션과 문제 해결에도 적극적으로 함께하고자 합니다.

팀장이라고 해서 일방적으로 방향을 정하기보다는, 각 파트의 의견을 충분히 듣고 **팀원들과 함께 고민하고 의사결정하는 방식**으로 프로젝트를 운영하고자 합니다.

그동안 여러 프로젝트와 활동을 통해 경험하고 배운 것들을 팀원들과 적극적으로 공유하며, 단순히 프로젝트 하나를 완성하는 것에 그치지 않고 **각자가 새로운 경험을 쌓고 한 단계 성장할 수 있는 프로젝트**가 될 수 있도록 함께 만들어가겠습니다.

### 협업 Tool

# 🙌 이런 분과 함께하고 싶습니다

개발 실력이 가장 뛰어난 사람보다는 끝까지 함께하며 적극적으로 참여할 수 있는 사람을 우선적으로 찾고 있습니다.

- 프로젝트를 중간에 포기하지 않고 끝까지 참여할 수 있는 분 (매우 중요!)
- 자신의 의견을 자유롭게 이야기할 수 있는 분
- 모르는 부분이 있더라도 공부하고 찾아보면서 해결하려는 분
- 다른 팀원의 의견과 피드백을 존중할 수 있는 분
- 연락 및 진행 상황 공유가 원활한 분
- 자신의 파트뿐만 아니라 서비스 전체에 관심을 가지고 참여하고 싶은 분
- 프로젝트 결과물을 포트폴리오와 취업 준비에 적극 활용하고 싶은 분

취준생, 대학생, 주니어 개발자 모두 환영합니다.

현재 실력이 완벽하지 않아도 괜찮습니다.

다만 프로젝트에 꾸준히 참여할 수 있는 시간, 책임감, 그리고 끝까지 완성하려는 의지는 중요하게 생각합니다.

# 💬 마지막으로

처음부터 완벽한 서비스를 만드는 것이 목표는 아닙니다.

> “팀 단위로 끝까지 만들어 보고, 배포하고, 사람들이 사용하는 서비스를 운영해 보자.”
> 

라는 목표를 가지고 시작하는 프로젝트입니다.

서로 부담 없이 의견을 나눌 수 있으면서도, 각자 맡은 부분에 대해서는 책임감을 가지고 참여하는 팀을 만들고 싶습니다.

프로젝트를 단순히 ‘해봤다’에서 끝내는 것이 아니라, 실제로 무엇을 고민했고 어떻게 협업했으며 어떤 결과를 만들어 냈는지 이야기할 수 있는 경험으로 함께 만들어 가면 좋겠습니다.
